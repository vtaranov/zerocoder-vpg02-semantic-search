# VPg02: смысловой поиск по средствам защиты

Консольный учебный проект: 24 вымышленных кратких описания превращаются в эмбеддинги OpenAI, сохраняются в Pinecone и находятся по смыслу. Девять запросов выводят ID, текст и численное сходство трёх результатов, реально возвращённых Pinecone. Среди вопросов есть неоднозначные и такие, для которых в базе нет ответа.

## Подготовка

Нужны Python 3.10+, аккаунты OpenAI и Pinecone и их API-ключи. Запросы к сервисам могут тарифицироваться. Клонируйте репозиторий и создайте окружение:

```bash
git clone https://github.com/vtaranov/zerocoder-vpg02-semantic-search.git
cd zerocoder-vpg02-semantic-search
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните `OPENAI_API_KEY` и `PINECONE_API_KEY` в `.env`. При использовании совместимого API укажите `OPENAI_BASE_URL`. Файл `.env` не публикуйте. По умолчанию создаётся индекс `vpg02-ppe` в AWS `us-east-1`, с размерностью 1536 и метрикой cosine; при необходимости выберите доступный регион и уникальное имя в `.env`. Используйте отдельный индекс или пространство имён: повторная загрузка перезапишет записи с теми же ID. Другие данные не удаляются.

```bash
python app.py setup
python app.py demo
python app.py search "Как защитить руки от острых краёв?"
```

`setup` создаёт индекс при отсутствии и отправляет 24 записи; это изменение в вашем аккаунте Pinecone. Удаление индекса в проекте не предусмотрено. После загрузки индексация может занять время. `demo` показывает девять запросов и три ближайшие записи для каждого. Автоматической оценки правильности и порога отсечения нет. Ближайшие записи возвращаются и для вопросов без ответа в базе. Сходство - не вероятность правильности. Существующий индекс проверяется по размерности и метрике; модель запроса и индексируемых текстов должна быть одинаковой. Для другой модели может потребоваться другая размерность и новый индекс.

Данные находятся в `data.json`, проверочные вопросы - в `queries.json`. Тематика учебная: реальные средства защиты выбирают по условиям и документации изделий.
